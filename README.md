# Financial Data Analysis & REST API Application

An automated Python data engineering and financial analytics application that fetches live time-series Forex data from a public REST API, cleans and normalizes dataframes, calculates market risk and return metrics using NumPy and Pandas, and programmatically compiles statistical reports and Seaborn visual dashboards.

> **Project Context:** Developed for **Task 4: Python Data & APIs** during the **Codomax Internship**.

---

## Key Features

1. **REST API Ingestion (`requests`)**: Interacts with the Frankfurter European Central Bank API to pull dynamic historical exchange rate matrices without requiring authentication keys.
2. **Tabular Processing & Cleaning (`pandas`)**: Parses nested JSON payloads, transforms dates into indexed time-series, handles missing values (market holidays), and exports structured CSVs.
3. **High-Performance Analytics (`numpy`)**: Evaluates daily log returns, 30-day rolling moving averages, annualized historical volatility ($V = \sigma \cdot \sqrt{252}$), and pairwise cross-asset correlation matrices.
4. **Visual Dashboard Generation (`matplotlib` & `seaborn`)**: Automatically creates and saves publication-quality 4-panel visual figures (trends, return distributions, box plots, and heatmaps).
5. **Markdown Report Compilation**: Automatically summarizes raw analytics into `reports/financial_report.md`.

## Installation & Setup
# 1. Clone & Set Up Environment
```
git clone [https://github.com/](https://github.com/)<your-username>/financial-data-analyzer.git
cd financial-data-analyzer

python -m venv venv
```
# macOS / Linux
```
source venv/bin/activate
```
# Windows
```
venv\Scripts\activate
```
# 2. Install Dependencies
```
pip install -r requirements.txt
```
3. Run the CLI Pipeline
```
# Run with default settings (EUR vs USD, GBP, JPY, CAD, CHF for 2024)
python main.py

# Or customize parameters
python main.py --start 2023-01-01 --end 2023-12-31 --base USD --symbols EUR GBP JPY
```
